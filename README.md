# Primitive DB

Консольная база данных на Python с поддержкой CRUD-операций и хранением данных в JSON-файлах.

## Возможности

- Создание, просмотр и удаление таблиц.
- Добавление, чтение, обновление и удаление записей.
- Фильтрация записей с помощью `WHERE`.
- Поддержка типов данных `int`, `str`, `bool`.
- Автоматическое создание уникальных идентификаторов `ID`.
- Проверка типов данных перед выполнением операций.
- Сохранение метаданных и записей между запусками программы.
- Кэширование результатов `SELECT`.
- Подтверждение операций удаления.
- Измерение времени выполнения операций.

## Требования

- Python 3.12 или новее.
- Менеджер пакетов [uv](https://docs.astral.sh/uv/).

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/nanysikc/project-2_Chelentano_M26-555.git
cd project-2_Chelentano_M26-555
```

Установите зависимости:

```bash
uv sync
```

## Запуск

Запустите программу:

```bash
uv run database
```

Также доступна команда:

```bash
uv run project
```

После запуска программа предложит ввести команду.

## Поддерживаемые команды

| Команда | Описание |
|---|---|
| `help` | Показать справку |
| `exit` | Завершить программу |
| `create_table` | Создать таблицу |
| `drop_table` | Удалить таблицу |
| `list_tables` | Показать существующие таблицы |
| `info` | Показать структуру и количество записей |
| `insert` | Добавить запись |
| `select` | Прочитать записи |
| `update` | Изменить записи |
| `delete` | Удалить записи |

## Пример использования

Создание таблицы:

```text
create_table users name:str age:int active:bool
```

Добавление записей:

```text
insert into users values ("Anna", 23, true)
insert into users values ("Max", 28, false)
```

Просмотр таблицы:

```text
select from users
```

Поиск по условию:

```text
select from users where age = 23
```

Изменение записи:

```text
update users set age = 24 where name = "Anna"
```

Удаление записи:

```text
delete from users where name = "Max"
```

Просмотр информации:

```text
info users
```

Удаление таблицы:

```text
drop_table users
```

Операции удаления требуют подтверждения.

## Хранение данных

Метаданные таблиц сохраняются в `db_meta.json`.

Записи каждой таблицы сохраняются в отдельном JSON-файле в каталоге `data/`.

Эти файлы создаются во время использования программы и не добавляются в Git.

## Структура проекта

```text
src/primitive_db/
├── __init__.py
├── main.py
├── engine.py
├── core.py
├── parser.py
├── decorators.py
├── constants.py
└── utils.py
```

- `main.py` — точка входа.
- `engine.py` — обработка пользовательских команд.
- `core.py` — основные операции базы.
- `parser.py` — разбор пользовательских значений и условий.
- `decorators.py` — декораторы, замыкания и кэширование.
- `constants.py` — константы проекта.
- `utils.py` — чтение и сохранение JSON.
